# Support

GitHub Issues are for product defects, public source corrections, installation
problems, and reusable workflow proposals. They are not a channel for advice on
an individual immigration, legal, tax, medical, financial, employment, housing,
or benefits case.

## Where to Report

- Use a **Bug report** when packaged behavior contradicts the documented
  contract or a supported host cannot load the complete plugin.
- Use a **Source update** when a competent official page moved or a packaged
  source fact is stale, incomplete, or conflicting.
- Use a **Workflow request** for a reusable, non-personal Poland workflow.
- Use [GitHub private vulnerability reporting](https://github.com/Xopoko/poland/security/advisories/new)
  for security issues.

## Never Include

Do not post names, addresses, contact details, PESEL or document numbers, case
numbers, credentials, cookies, one-time codes, account records, personal
documents, correspondence, screenshots, unredacted logs, or a personal case
narrative. Use a minimal synthetic reproduction.

For an individual situation, contact the competent authority or an appropriate
qualified professional. For immediate danger, use the appropriate official
emergency or crisis service; do not wait for a project response.

Maintainers cannot guarantee response times, source freshness, eligibility, or
an administrative outcome. See the [Disclaimer](DISCLAIMER.md).
